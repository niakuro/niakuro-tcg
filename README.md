# 現在のルール整理（2026-11-20 時点・仮置き含む）

## 勝利条件
- 戦線ゲージ −15〜+15 の押し合い。端まで押し切ったら勝ち。
- 目安として、お互い12ターンくらいで終わる想定。

## ポイント（リソース）
- 最初のターンは2ポイント、自分のターンごとに基本ポイントが+1（上限なし）。
- 使い残しの半分（切り捨て）が次のターンに繰り越される。

## カードとデッキ
- 種類は2つ: ユニット（場に出て攻撃）/ 戦術（使い切りの効果）。（武装は廃止した）
- 能力値の目安: 攻撃力+体力 ≒ コスト×2。強い効果を持つものはその分下げる（カード毎に微調整）。
- デッキは40枚、同名カードは3枚まで。初期手札5枚、毎ターン1ドロー。
- マリガン: 手札を全部引き直すかそのままか、一回だけ。
- 手札上限10枚（自分のターン終了時に超えていたら捨てる）。デッキ切れで引けないと負け。

## 攻撃と戦闘
- 攻撃先は自由（プレイヤー or ユニット）。出したターンは攻撃できない。ブロックなし（止める手段は先に倒すか、効果持ちカード）。
- プレイヤーへの攻撃: ダメージ分ゲージが動く（一番効率のいい押し方）。
- ユニット同士: お互いの攻撃力分を食らい合う（反撃あり）。ダメージはターン終了後も残る。
- 戦闘で倒すと、倒したユニットのコストの半分（切り捨て・最低1）ゲージが動く。相打ちは両方向の差分だけ動く。
- 効果（除去など）で倒した場合はゲージは動かない。

## キーワード能力
- **速攻** ― 出たターンでも攻撃できる。
- **先手必勝** ― 出たターンでも、相手のユニットを攻撃できる（プレイヤーへの攻撃はできない）。
- **守護** ― 相手は守護を持つユニットしか攻撃できない（顔も、守護でないユニットも攻撃できない）。守護が複数いれば、その中から攻撃対象を選ぶ。効果の対象には影響しない。
- **連携○：特徴** ― 自分の場に「自分以外の」その特徴を持つユニットがいる間、攻撃力が○上がる（例: 連携2：古参 = 他の古参がいれば攻撃力+2）。条件を満たすユニットが何体いても、ボーナスは1回だけ。効果で付与された連携は、もともと持っている連携と重なる（例: 連携2持ちに連携1が付くと連携3）。
- **秩序なき連携ニトグリのオーラ** ― 他の悪友がいれば、その悪友と自身は攻撃力+1・体力最大値-1。他の善友がいれば、その善友と自身は体力最大値+2。両方の特徴がそろえば自分のユニット全員が速攻を得る。
- **覗き見** ― ゲーマーにあくろは他の悪友がいる時に限り、相手の手札を見て1枚選んで捨てる。見たカード自体は公開状態にならない。

## 背水の陣
- 攻撃でゲージの残りが5以下になった瞬間に必須発動（温存できない）。各プレイヤー1回だけ。
- 次の3つから1つ選ぶ: (1) ゲージを3押し戻す (2) 4枚ドロー (3) 次の自分のターンのポイント+3。
- 先に選ばれた行動は、相手は選べない（封じ合い）。
- 背水の陣が未使用のプレイヤーは、一撃で端まで押し切られても「残り1」で止まる。
  ただし専用のフィニッシャーカードだけは、この保護を貫通して一撃で押し切れる。

## 先攻・後攻
- 後攻補正: 後攻は初期手札が+1枚（追加ドロー）、最初のターンのポイント+1。

## その他
- 場に出せるユニットは5体まで。
- 戦闘部分は今は王道（シャドバ等に近い形）で仮置き。オリジナルの工夫を足すのは余裕ができてから。
- オリジナル要素の核: ポイント繰り越し / 戦線ゲージ / 背水の陣。
