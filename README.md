# ルールメモ（2026-11-20／仮案）

## 勝ち方
- 戦線ゲージは−15〜+15。相手側の端まで押し切ったら勝ち。
- 僕は12ターンくらいで終わるバランスを目指して調整中。

## ポイント
- 最初は2ポイント。自分のターンごとに基本ポイントを+1（上限なし）。
- 使い残しの半分（切り捨て）を次のターンに繰り越す。

## カードとデッキ
- カードはユニット（場に出して攻撃）と戦術（使い切り効果）の2種類。武装は廃止。
- 僕の能力値の目安は「攻撃力+体力≒コスト×2」。強い効果のカードは、その分ステータスを控えめに。カードごとに調整中。
- デッキは40枚。同名カードは3枚まで。初期手札は5枚、毎ターン1枚引く。
- マリガンは手札を全部引き直すか、そのままにするかを1回選ぶ。
- 手札上限は10枚。自分のターン終了時に超えていたら捨てる。デッキ切れで引けなかったら負け。

## 攻撃と戦闘
- 攻撃先はプレイヤーかユニット。出したターンは攻撃できない。ブロックなし（止めるなら先に倒すか、効果カード）。
- プレイヤーを攻撃すると、ダメージ分だけゲージが動く。いちばん効率のいい押し方。
- ユニット同士は攻撃力分のダメージを与え合う（反撃あり）。ダメージはターン終了後も残る。
- 戦闘で倒したら、倒したユニットのコストの半分（切り捨て・最低1）だけゲージが動く。相打ちは両方向の差分。
- 効果で倒してもゲージは動かない。

## キーワード能力
- **速攻** ― 出たターンから攻撃できる。
- **先手必勝** ― 出たターンから相手ユニットを攻撃できる（プレイヤーは攻撃できない）。
- **守護** ― 相手は守護持ちしか攻撃できない。守護が複数いれば、その中から選ぶ。効果の対象には影響なし。
- **連携○：特徴** ― 自分以外の味方に同じ特徴がいれば攻撃力+○。条件を満たす味方が何体いてもボーナスは1回。効果で付いた連携は、もとの連携に加算。
- **秩序なき連携ニトグリのオーラ** ― 他の悪友がいれば、その悪友と自身は攻撃力+1・体力最大値-1。他の善友がいれば、その善友と自身は体力最大値+2。悪友と善友の両方がいれば、自分のユニット全員が速攻を得る。
- **覗き見** ― 他の悪友がいる時、ゲーマーにあくろが相手の手札を見て1枚選んで捨てる。見たカードは公開状態にならない。

## 背水の陣
- 攻撃でゲージの残りが5以下になったら必ず発動。温存できない。各プレイヤー1回だけ。
- 次から1つ選ぶ：(1) ゲージを3押し戻す (2) 4枚引く (3) 次の自分のターンのポイント+3。
- 先に選ばれた行動は相手が選べない。
- 背水の陣を使っていない相手は、一撃で押し切られても残り1で止まる。専用フィニッシャーだけはこの保護を貫通。

## 先攻・後攻
- 後攻は初期手札+1枚、最初のターンのポイント+1。

## ほか
- 場に出せるユニットは5体まで。
- 戦闘はまず王道寄り（シャドバっぽい形）で仮案。オリジナルの工夫はあとから足す。
- 僕が大事にしたい核は、ポイント繰り越し・戦線ゲージ・背水の陣。
