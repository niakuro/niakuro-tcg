# カード一覧と構築済みデッキ（2026-11-19 時点）

## メンバーカード（計26体 — にあくろ・ニトグリは各5体、ほか4人は各4体）

特徴タグ: 現在のメンバー全員のユニットが「古参」を持ち、にあくろ・ニトグリ・ココナッツのユニットは追加で「悪友」を、マスカット・やーや・ミルキーのユニットは追加で「善友」を持つ。特徴は効果の対象指定（「古参を強化する」など）に使える。

能力値の目安は「攻撃力+体力 ≒ コスト×2」。効果持ちはその分下げてある。
「実装済み」はエンジンが自動で解決する効果、「未実装」は対象選択などの仕組みができてから足す効果。

## 効果テキストの書き方（統一ルール）
- 文は「。」で終え、効果ごとに文を分ける。
- 登場時効果は「登場時、」で始める。常時効果は「このユニットが場にいる間、」で始める。
- 対象を取る効果は「相手のユニット1体」「自分のユニット1体」のように持ち主＋対象＋数を明記し、選ぶ場合は「選ぶ」を入れる。
- 動作の言葉は統一する: ダメージは「○ダメージを与える」、ドローは「カードを○枚引く」、回復は「体力を○回復する」、増減は「攻撃力を+○する」「体力の最大値を-○する」。
- キーワード（連携・速攻・フィニッシャー）は名前を書き、必要な時だけ括弧で短く補足する。

### 共通の戦術
- 紳士の嗜み（戦術・コスト1）: カードを2枚引く

- 不可視の爆撃（戦術・コスト3）: 相手のユニット1体を選び、3ダメージを与える
- 一斉射撃（戦術・コスト4）: 相手のユニット全てに1ダメージを与える
- 三兎追えば二兎得る（戦術・コスト3）: カードを3枚引く。その中から2枚を選び、手札に加え、残りを墓地に置く
- ゲームの準備（戦術・コスト4）: 自分のデッキから戦術をランダムに2枚、手札に加える
- 酒！酒！酒！（戦術・コスト3）: 自分のユニット1体を選び、攻撃力を+2し、体力の最大値を-2する。そのユニットは攻撃した後に破壊される

- ちゃぶ台返し！（戦術・コスト6）: お互いのユニット全てに3ダメージを与える

- 最前線攻略tv⁉︎（戦術・コスト3）: 自分の基本ポイントを+1する
- にあくろの遊び心（戦術・コスト3）: 相手の手札をランダムに1枚捨てる
